# Gourinandhan Saijush — Robotics & AI Portfolio

A responsive, static portfolio built with HTML, CSS and a small amount of JavaScript. It presents education, engineering experience, internships, projects, technical skills, certifications and professional links.

## Preview locally

Open `index.html` directly, or serve this directory with any static web server. The site has no build step or package dependencies.

## Project files

- `index.html` — page content and lightweight scroll-reveal behavior.
- `styles.css` — responsive layout, color system and reduced-motion handling.
- `Gourinandhan_Saijush.pdf` — downloadable CV.
- Image files in the repository — profile photo and certificate scans used by the page.

The repository is published with GitHub Pages from the `main` branch.
